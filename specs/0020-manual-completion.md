# Spec 0020: Manual Completion

## Status

Final baseline.

## Purpose

This spec defines user-facing and developer-facing manual requirements for Hawk2UI.

## User Manual Requirements

The user manual must include:

- installation,
- project creation,
- desktop application workflow,
- plugin editor workflow,
- manifest reference,
- style reference,
- layout reference,
- asset reference,
- runtime API reference,
- platform capability reference,
- packaging guide,
- troubleshooting guide,
- examples index.

## Developer Manual Requirements

The developer manual must include:

- crate map,
- public API contracts,
- artifact schemas,
- renderer boundary,
- host adapter boundary,
- runtime binding boundary,
- plugin adapter boundary,
- security model,
- compatibility matrix,
- performance gates,
- release process,
- contribution workflow.

## Example Requirements

Examples must include:

- complete source files,
- manifest files,
- style files,
- asset declarations,
- build commands,
- run commands,
- expected diagnostics for failure cases,
- expected output descriptions.

## Documentation Verification Requirements

Documentation checks must validate:

- internal links,
- referenced files,
- command snippets,
- API coverage,
- example coverage,
- version alignment,
- stale compatibility references.

## Acceptance Criteria

- Manuals cover user workflows and developer implementation contracts.
- Public APIs have documentation coverage.
- Examples are runnable through documented commands.
- Documentation checks are release gates.
