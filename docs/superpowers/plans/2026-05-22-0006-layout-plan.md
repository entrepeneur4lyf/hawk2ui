# Layout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement layout trees, text measurement integration, plugin editor constraints, and scene geometry output.

**Architecture:** Keep layout as a pure calculation layer that accepts typed style and text measurement inputs, then attaches geometry to scene nodes. Custom measured nodes reserve space through explicit callbacks.

**Tech Stack:** Rust, taffy, serde, cargo test, insta snapshots.

---

## File Structure

- Create: `crates/hawk2ui-layout/src/lib.rs` layout API exports.
- Create: `crates/hawk2ui-layout/src/tree.rs` layout tree records.

- Create: `crates/hawk2ui-layout/src/scene.rs` scene geometry attachment.
- Create: `crates/hawk2ui-layout/tests/layout_behavior.rs` layout tests.
