# Testing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the shared test infrastructure for unit, integration, visual regression, host lifecycle, plugin lifecycle, security rejection, artifact verification, performance, and dependency hygiene gates.

**Architecture:** Test utilities live in a dedicated crate so every domain can use deterministic fixtures and shared assertions. CI-like local commands become the required verification gate before commits.

**Tech Stack:** Rust, insta, criterion, cargo-deny, cargo-audit, trycmd, cargo test.

---

## File Structure

- Create: `crates/hawk2ui-testkit/src/lib.rs` shared test helpers.
- Create: `crates/hawk2ui-testkit/src/fixtures.rs` deterministic fixtures.
- Create: `crates/hawk2ui-testkit/src/visual.rs` visual regression helpers.
- Create: `crates/hawk2ui-testkit/src/security.rs` security rejection helpers.
- Create: `crates/hawk2ui-testkit/src/perf.rs` benchmark helpers.
- Create: `tests/integration/source_to_render.rs` workspace integration test.
- Create: `benches/render_baseline.rs` benchmark entrypoint.
- Create: `deny.toml` dependency hygiene policy.
