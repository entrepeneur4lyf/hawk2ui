# Style Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Compile documented style source into typed style records with build-time validation, selector matching, tokens, and runtime-safe property values.

**Architecture:** Parse source into validation records, then lower into typed property tables. Runtime code consumes typed values only and never depends on raw string maps.

**Tech Stack:** Rust, lightningcss for parsing where appropriate, serde, indexmap, cargo test, insta snapshots.

---

## File Structure

- Create: `crates/hawk2ui-style/src/lib.rs` style API exports.
