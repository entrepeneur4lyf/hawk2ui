# Security Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement trust-boundary records, build-time source validation, script sandbox policy, asset security checks, secret redaction, and package trust validation.

**Architecture:** Security policy is enforced at build validation and runtime binding lookup. Runtime receives trusted compiled records and structured denied-access diagnostics.

**Tech Stack:** Rust, serde, blake3, SVG sanitizer behind internal trait, cargo test, insta snapshots.

---
